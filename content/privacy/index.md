# 隐私政策 (Privacy Policy)

**生效日期：2026年10月**

「机场预算」（jichangyusuan.cc）高度重视用户的隐私权利与数据安全。本隐私政策旨在透明披露我们对用户数据的处理原则。

---

## 1. 核心承诺：零敏感数据采集

- **纯前端本地内存运算**：站内提供的所有计算器（首付精算、年付对比、折扣核算、续费估算、流量成本）全部基于 JavaScript 纯函数在您的**本地浏览器内存**中实时执行。
- **不上传输入数据**：您在计算器输入框中填写的任何预算金额、流量用量、折扣数值或设备数量，**绝不会**通过网络请求上传至本站或任何第三方服务器。
- **无用户注册与登录**：本站不设任何用户账户体系、数据库或 Cookie 跟踪凭据，无需提供邮箱、手机号或实名信息即可使用全部功能。

---

## 2. 静态日志与技术访问记录

作为部署在 Apache 静态服务器上的标准网站，托管服务商的基础设施可能会在访问时记录标准的 Web 服务器访问日志（包括访问时间、HTTP 状态码、请求的文件路径、浏览器 User-Agent 及来源 IP）。该日志仅用于防御恶意 DDoS 攻击与保障服务器基础可达性，绝不与任何个人输入相关联。

---

## 3. 第三方转介链接

当您点击站内的选购交接按钮（前往协作主站「机场榜一」`jichangbang.org`）时，链接会附带标准的渠道标识（UTM 参数，如 `utm_source=jichangyusuan.cc`），用于统计不同专题的转介热度。这些参数不包含任何您的个人身份信息或刚才计算的预算结果。

---

## 4. 政策更新与联系

如本站因技术架构升级或法律法规变动需要更新隐私政策，我们将在本页面公开发布最新版本。若有任何疑问，请联系：`privacy@jichangyusuan.cc`。
