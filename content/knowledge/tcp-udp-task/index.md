## 4. 常见反例与边界防坑提示

在落实“TCP与UDP的作用有什么不同，选服务时应如何对应实际应用”的过程中，切忌陷入以下典型思维陷阱：

### 反例 1：在极其老旧的单核路由器上强跑双重混淆协议
路由器 CPU 占用瞬间飙至 100%，导致全家网络卡死，误以为是机场网速慢。

### 反例 2：在完全封禁 UDP 的校园网或公司内网尝试连接基于 QUIC 的节点
端口完全无法握手成功，应直接切换回标准 443 端口的 TCP 协议。

### 反例 3：误以为协议越复杂、节点套的 CDN 越多就越快
每多一层中转就会增加几十毫秒物理延迟并成倍消耗服务器算力，直连专线永远最快。
